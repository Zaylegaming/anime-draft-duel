# Anime Draft Duel

Jeu de draft de personnages d'animé en duel, à 2 joueurs (même écran ou en ligne).

- `android/` : application Android (WebView). L'APK se compile automatiquement à chaque envoi sur `main` (onglet **Actions**) et se télécharge depuis la page **Releases**.
- `pc/` : fichiers de l'application Windows (Electron).
- `android/app/src/main/assets/index.html` : le jeu lui-même.

L'appli ne contient aucune image : chaque joueur ajoute les siennes depuis l'écran « Artworks des personnages ».
